Project Proposal: Tennis Match Predictor
Course: Introduction to Machine Learning
Menczel Kornél, Herczeg Balázs

Project Overview
The goal of this project is to develop a predictive model that estimates the outcome of professional tennis matches (ATP/WTA) using historical performance data. Unlike simple ranking-based predictions, this model will analyze a variety of technical and environmental features to determine the probability of victory for each player.

Key Features & Data Points
The model will leverage historical match statistics, including:

Player Performance: Serve speed, first-serve percentage, break points saved, and unforced error rates.

Contextual Variables: Head-to-head records, surface type (Clay, Grass, Hard), and current world ranking.

Psychological Factors: Recent momentum (win/loss streaks) and performance under pressure (tie-break win rates).

Methodology
We plan to implement and compare several supervised learning algorithms, such as Logistic Regression for a baseline, and more advanced models like Random Forests to capture non-linear relationships in the data. Success will be measured using accuracy, precision, and F1-score against a test set of recent tournament results.
